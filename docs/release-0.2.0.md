## Fast Music 0.2.0

Компактный плеер Яндекс Музыки в строке меню macOS: без окна в Dock и браузерного движка.

### Скачать и установить

1. Скачайте **Fast-Music-0.2.0-universal.dmg** из раздела Assets ниже.
2. Откройте образ и перетащите **Fast Music.app** в **Applications**.
3. Запустите приложение из «Программ». Жёлтая звезда появится в строке меню.
4. Нажмите «Войти» и подтвердите код на сайте Яндекса. Для полных треков нужна подписка Плюс.

**macOS 14 Sonoma и новее · Apple Silicon и Intel · universal-сборка.**

### Первый запуск

Приложение подписано локальной ad-hoc подписью, **без Apple Developer ID и нотарификации**. Если macOS заблокирует открытие, после попытки запуска откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. Название кнопки зависит от версии macOS. Отключать системную защиту целиком не нужно.

### Возможности

- Моя волна, поиск, собственные плейлисты и любимые треки.
- Пауза, переключение треков, перемотка, громкость и лайк.
- Компактная панель, исправленные обложки и выравнивание ползунков.
- Настраиваемые сочетания: **⌘⇧M** — панель, **⌘⇧W** — волна, **⌘⇧L** — любимое; **⌘F** — поиск внутри панели.
- Автозапуск через настройки приложения. На новом Mac включается пользователем.
- Токен аккаунта хранится в macOS Keychain.

### Проверка сборки

Собрано из исходников тега `v0.2.0`; DMG проверен `hdiutil verify`, обе архитектуры — `lipo`, подпись приложения — `codesign`. Рядом приложен SHA-256. На Apple Silicon выполнена проверка запуска/рендера; **на физическом Intel Mac эта версия не тестировалась**.

Ранняя версия неофициального клиента. API Яндекса может меняться. Поиск пока показывает первую страницу; горячая клавиша любимого запускает очередь до 100 треков. Полные ограничения описаны в README.
