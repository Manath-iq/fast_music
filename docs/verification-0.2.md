# Проверка версии 0.2 — 23.11.2026

- `swift test`: 5 тестов, 0 ошибок. Проверены границы сетевых адресов, нормализация обложек, размерные пресеты, метаданные альбома, модификаторы сочетаний и физический код клавиши.
- `bash scripts/build.sh`: release arm64 успешно. `codesign --verify --deep --strict` установленной `.app`: успешно.
- Визуально просмотрены нативные рендеры основного экрана и настроек. Ширина 392pt; брендовый заголовок и фоновые градиенты убраны. Ползунки используют одну ось для дорожки и ручки.
- Подтверждена причина ошибки обложек на публичном треке: `.../240x240` → HTTP 404; `.../200x200` → HTTP 200, JPEG 200×200. Учетные данные для проверки не использовались.
- Приложение установлено в `~/Applications/Fast Music.app`, запущен новый процесс. Автозапуск зарегистрирован через SMAppService; `sfltool dumpbtm` показывает для `site.manath.fastmusic` **enabled, allowed, notified**, путь установленного приложения.
- Глобальные сочетания регистрируются Carbon RegisterEventHotKey, без постоянного мониторинга всех нажатий клавиатуры. Для записи нового сочетания старые регистрации временно снимаются; при отмене/закрытии восстанавливаются.
- Добавлены глобальный монитор кликов вне приложения, локальный монитор кликов по другим окнам и закрытие при потере активности. ⌘F обрабатывается только внутри панели; запись сочетания исключена из обработчика.

Ограничения проверки: автоматическое управление настоящим окном через Accessibility недоступно в этой сессии. Нажатие глобальных сочетаний, закрытие по клику и воспроизведение персонального избранного требуют живой пользовательской проверки. Регистрация автозапуска проверена, реальный выход/вход в macOS не выполнялся. Наличие новой регистрации не является проверкой всех межприложенных конфликтов клавиш.
